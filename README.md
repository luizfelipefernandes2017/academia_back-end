# Academia incrivel hulk

Sistema web desenvolvido para a Academia Corpo em Movimento.

O projeto permite que a proprietária cadastre modalidades e turmas pelo painel administrativo. Também possui uma página inicial pública e uma página pública com a grade de turmas.

## Equipe

- Nome da equipe: Luiz Felipe e Jully
- Repositório: academia_back-end

## Tecnologias utilizadas

- Python 3
- Django
- SQLite
- HTML
- Git e GitHub

## Funcionalidades

- Cadastro, edição, consulta e exclusão de modalidades pelo painel administrativo.
- Cadastro, edição, consulta e exclusão de turmas pelo painel administrativo.
- Filtro de turmas por modalidade.
- Filtro de turmas por dia da semana.
- Busca de turmas pelo nome do instrutor.
- Filtro de modalidades ativas e inativas.
- Página inicial com as modalidades ativas.
- Página pública com a grade de turmas.
- Menu de navegação entre as páginas públicas.
